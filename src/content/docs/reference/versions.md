title: Supported versions
description: The Minecraft versions and loaders Archive World Downloader ships builds for, and the settings each one leaves out.

The mod ships one build per Minecraft version and loader. These are the exact versions built, so a version missing from the table has no build.

A setting your Minecraft version cannot support is hidden.
