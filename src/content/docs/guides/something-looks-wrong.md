Start from what you saw. Each entry below quotes the words on screen and links to the page that covers them.

## Something went wrong with a download

A download that ends badly says so on screen in one of a few ways. Find the one you saw.

- It says **"Partial"** on the download's row: [a "Partial" download](/guides/download-failed/#a-partial-download).
- It says **"Save failed"**: ["Save failed"](/guides/download-failed/#save-failed).
- It shows a **"⟲ Recover"** chip: [after a crash](/guides/download-failed/#after-a-crash).

## A container still has an outline

The same outline means two different things depending on what you did. One you never opened is simply still waiting; one you did open and it stayed outlined anyway was missed, and a second open saves it.

- You never opened it: [container outline](/guides/check-coverage/#container-outline).
- You opened it and the outline stayed: [when a container you opened is not saved](/concepts/what-gets-downloaded/#when-a-container-you-opened-is-not-saved).

## Resuming is blocked, or a Map looks wrong

A refused resume changes nothing, and a downloaded Map that looks odd is usually behaving as designed. Find the one you saw.

- It says **"Resume blocked"** or **"Can't resume"**: [restore a download you opened in singleplayer](/guides/restore-download/).
- A Map says **"Locked"**: [why downloaded Maps are locked](/concepts/maps/#why-downloaded-maps-are-locked).
- You got a **"Different map ID scheme"** warning: [resume an interrupted download](/guides/resume-download/#a-different-map-id-scheme-warning).
